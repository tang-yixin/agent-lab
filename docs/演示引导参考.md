## 1. 演示完整流程（按这个顺序讲）

### 第 1 步：开场（30 秒）

**动作**：展示项目简介，一句话说清系统是干什么的。

**主动说明**：
> "这是一个由 Agent 驱动的大数据处理系统。用户在前端用自然语言提出需求，Agent 自动调用 Hadoop 完成数据清洗和质量评估，全程不需要手动跑命令。"

---

### 第 2 步：证明"Hadoop 集群是真的在跑"（1 分钟）⭐ 重点主动展示

**动作**：切到 `localhost:9870` 和 `localhost:8088` 两个标签页。

**主动说明**（指着 9870 页面）：
> "这是 Hadoop 的 **NameNode 监控界面**（HDFS 主节点）。注意这行 `Live datanodes: 1`，说明数据节点在线；`Safemode is off` 说明文件系统已经就绪，可以正常读写。这个页面不是静态网页，是 NameNode 进程自己开的 HTTP 服务，能打开就说明这个进程真的活着。"

**主动说明**（指着 8088 页面）：
> "这是 **ResourceManager 监控界面**（YARN 资源管理器）。这里能看到集群的计算资源和作业列表——等会儿我跑一次任务，这里会实时出现一个新的作业记录，可以证明作业是真正提交到 Hadoop 上执行的。"

> 💡 **为什么这步重要**：这是回应"你们是不是用假的/模拟的结果"最有力的证据。主动展示，比被老师问"Hadoop 真跑了吗"再解释强得多。

---

### 第 3 步：在前端发起一次完整任务（1~2 分钟）⭐ 核心

**动作**：切回前端页面，点「默认清洗评估」快捷按钮（或手动输入那句完整提示语）。

**主动说明**（任务跑起来时，指着"执行情况"区）：
> "现在任务正在执行。注意看这里的**执行状态**——它会实时显示'正在执行'，下方**时间线**会依次出现四个步骤：清洗前评分 → 数据清洗 → 清洗后评分 → 读取隔离样例。每一个步骤背后都是一次真实的 Hadoop MapReduce 作业。"

**等待时说明**：
> "这需要一两分钟，因为每个评分/清洗作业都要真正启动 MapReduce，处理 100 多万条记录。"

---

### 第 4 步：解读结果（2~3 分钟）⭐ 核心

任务完成后，**按顺序主动讲三块**：

**① 五维评分对比**（指着雷达图和柱状图）：
> "左侧雷达图和柱状图展示了五个维度的清洗前后对比。可以看到：唯一性 Unique 从 92 分提升到 100 分（去掉了重复记录），准确性 Accurate 从 94 提升到 100。综合分从 95.27 提升到 100。"

**② 数据量变化**（指着统计卡）：
> "数据量从清洗前的 116 万条，变成清洗后的 100 万条。这里关键要讲清楚：我们区分了三种处置——**修复** 9897 条（能确定正确值的就地改正）、**去重** 294 条（完全重复的删除）、**隔离** 15.5 万条（无法确定正确值的，标记后移出主数据集，**没有删除**）。隔离不等于修复，这点很重要。"

**③ Agent 解释**（指着下方文字）：
> "Agent 自动生成了完整的解释报告，它明确指出：'清洗后满分不代表数据完美，因为满分是幸存者偏差的结果，格式正确也不等于内容真实'。这是系统的一个诚实立场。"

---

### 第 5 步：展示结果获取与历史报告（1 分钟）

**动作**：指着右侧「结果获取」卡片。

**主动说明**：
> "用户可以在这里查看清洗后的数据样例、隔离记录样例（带隔离原因），也可以下载完整的评估报告。下方还有**历史报告列表**——每次任务都会自动归档一份，带任务 ID 和时间戳，实现了版本追溯。"

**动作**（可选）：点一下某个历史报告，展示能下载/查看任意一次结果。

---

### 第 6 步：展示追问能力（1 分钟）⭐ 加分项

**动作**：在输入框问一句追问，比如"隔离了哪些类型的异常？分别有多少？"

**主动说明**：
> "系统还支持追问。它会带着之前的上下文回答——刚才我问了隔离情况，它基于真实的隔离样例来回答，而不是背台词。"

---

### 第 7 步：主动说明局限（1 分钟）⭐ 体现思考深度

**动作**：口头补充，不需要操作。

**主动说明**：
> "最后我要主动说明系统的几个局限，这也是题目要求的'如实说明未解决的问题'：
> 1. 隔离的 15.5 万条记录问题本身还没解决，需要人工复核；
> 2. 清洗后满分不代表数据真实，格式正确无法验证内容真实性；
> 3. 历史数据（2000-2003 年）的时效性只能说明'时间戳格式合规'，不代表反映当下。
> 另外我们定好了时间边界 T1（2000-12-31）和 T2（2001-12-31），这是给后续迭代做机器学习时防止数据泄漏用的。"

## 2. 高频提问速答（老师问到时怎么答）

| 问题 | 回答要点 |
| --- | --- |
| "评分公式是你自己定的吗？" | 题目只给五维含义，口径由学生设计。我用"记录级判定 + 数据集级聚合"，每维 0~100 分，权重 Accurate/Complete 各 0.25、Unique/Consistent 各 0.20、Up-to-date 0.10 |
| "为什么清洗后 100 分？" | 主动说是"幸存者偏差"——异常被隔离后剩下的自然全合规，分数提升主要来自剔除而非修好，这恰恰是批判性认识 |
| "隔离和删除什么区别？" | 隔离=标记移出不删，问题未解决；删除=物理移除。我们选隔离更诚实 |
| "Hadoop 真跑了吗？" | 现场切 9870/8088 两个 Web UI，展示 Live datanodes + 作业记录 |
| "T1/T2 现在有啥用？" | 迭代一不训练，但提前立边界防后续迭代数据泄漏 |
| "数据里有什么脏数据？" | 评分 3.5/five/0/6、毫秒时间戳、逗号/竖线分隔符、Gender=X、Age=30、Occupation=99、UnknownGenre、跨表孤儿 |

## 4. 一句话记住每个"主动说明"的时机

> **不要等老师问，而是每展示一个东西，就主动补一句"这意味着什么"**：
> - 打开 Web UI → "这证明 Hadoop 进程真的活着"
> - 跑任务 → "每个步骤都是真实 MapReduce 作业"

> - 看数据量 → "隔离≠删除，问题没解决"
> - 收尾 → "我们主动说局限 + T1/T2"
